# FeatherFramework

一个基于 **Unity** 的轻中度游戏开发框架，旨在提供便捷的工具和功能，以加速游戏开发进程。

## 功能特点

- **UI 框架**: 对UI面板进行管理，包括完整的生命周期及UI常用功能。支持预制体一键生成对应脚本。
- **音频管理**: 方便管理和播放游戏音效及音乐。
- **配置表读取**: 集成了Luban工具，支持多种格式的配置表数据读取。
- **数据持久化**: 简化数据保存与加载的流程。
- **红点系统**: 实现红点功能，支持配置表。
- **多语言模块**: 支持国际化和多语言切换。
- **跨平台日志Log**: 使用了Log Viewer插件。
- **常用插件集成**: 包括DOTween、Odin、EasySave等。
- **以及其它常用功能**
